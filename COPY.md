# SkyFreedom — język interfejsu

Krótka etykieta mówi, co widać. Przycisk mówi, co się stanie.

| Miejsce | Etykieta lub działanie | Potwierdzenie |
| --- | --- | --- |
| Operator | Uruchom lot / Zatrzymaj lot | Symulowany lot uruchomiony / zatrzymany |
| Kamera | RGB / Termiczny | Tryb termiczny jest symulowany |
| Operator | Zgłoś zdarzenie | Zgłoszenie przekazano dowódcy |
| Dowódca | Potwierdź zdarzenie | Zdarzenie potwierdzone |
| Dowódca | Przekaż alert jednostce | Alert trafił do jednostki terenowej |
| Jednostka | Omiń drogę 14 | Objazd przez most północny |
| Dowódca | Zamknij zdarzenie | Zdarzenie zamknięte |
| Mapa | Wszystko / Drony / Zdarzenia | Wybrana warstwa pozostaje oznaczona |

Słowa „symulacja”, „poglądowe” i „obraz poglądowy” pojawiają się przy mapie, kamerach, czujnikach oraz w stopce. Nie używamy „na żywo” dla statycznych ilustracji.
